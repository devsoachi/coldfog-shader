This shaderpack intends to make the game look like a foggy and hostile enviroment, where is hard to look further and giving a real terror feel using GLSL code on the 3D mod, Project Viewpoint for Project Zomboid. Uses different techniques to adapt this onto the game.

### Latest [Release](../../releases/latest) here.

## Features:
1. Pixelated effect and wobble, made for give the game a retro-like feel.
2. Uses Chromatic Aberration, Bloom, a Blue Contrast.
3. Everything is configurable, whether if you want a real cold feel or a more green feel.
4. A endless fog.

## Recommended Settings:

### Pixelated effect:
	pixel 3.0
	colorbits 5.0
	wobble 0.5

### A really constant mist:
	Constant Mist 0.12
	Max Visibility 0.25
